## Project Overview

**babel-fish** — a technical-to-feature-level human translator with drift management. Translates technical implementation details into human-readable feature descriptions while tracking and managing semantic drift over time.

## Current State

This is a greenfield project with no source code yet. The repo contains only a README.md.

## Project Map

**Project Map**: For any project-specific question, read
[`.claude/project-map/PROJECT_MAP.md`](.claude/project-map/PROJECT_MAP.md) —
auto-generated index of routes, models, import chains, infra profile,
and vocabulary translator. Regenerated automatically on commit.

```bash
python .claude/project-map/generate.py --force
```

## Documentation

Prose documentation lives in [`.documentation/`](.documentation/), managed by
[`hit-em-with-the-docs`](https://github.com/TheGlitchKing/hit-em-with-the-docs).
Start at [`.documentation/INDEX.md`](.documentation/INDEX.md). Every doc carries
YAML frontmatter (`title`, `tier`, `domains`, `status`, `last_updated`, `version`).

New docs go in the matching domain folder — not the repo root, not a new `docs/`
directory. After adding or editing one:

```bash
hewtd maintain    # reindex + link-check + audit
```

Not managed here (leave in place): `README.md`, `CHANGELOG.md`, `LICENSE` (npm
`files:` + registry rendering), `.claude/rules/*.md` and `.claude/project-map/**`
(auto-generated by babel-fish itself), and `.planning/**` (owned by
persistent-planning).
